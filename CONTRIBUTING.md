# Contributing

Thanks for your interest in Afterlid.

- **Found a bug or have an idea?** Open an issue using the bug report or feature request template.
- **Want to send a fix?** Pull requests are welcome. Fork the repo, make your change on a branch, and open a PR against `main`. Keep it focused on one thing and describe how you tested it.

All pull requests are reviewed and merged by the maintainer. Not every PR will be accepted, especially ones that add a lot of scope; opening an issue first to discuss bigger changes saves everyone time.
